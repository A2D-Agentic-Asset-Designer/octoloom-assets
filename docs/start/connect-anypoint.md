# Connect Octoloom to Agent Fabric

1. Click **Connect Agent Fabric** (or run *Octoloom: Connect to Agent Fabric*). <video controls muted playsinline preload="none" poster="../../assets/onboarding/videos/octoloom-connect-anypoint.png" src="../../assets/onboarding/videos/octoloom-connect-anypoint.mp4" aria-label="Video: connect Octoloom to Agent Fabric with the client ID and secret of Octoloom-CA" style="width:100%"></video>
2. Paste the **Client ID** and **Client Secret** of `Octoloom-CA`.
3. Pick the **business group** (root first) and the **environment** where your gateway runs.

**Setup & Connect** shows a green light for Agent Fabric when the connection works. Change the environment later with *Octoloom: Select Agent Fabric Environment*.
