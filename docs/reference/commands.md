# Commands

All commands are under the **Octoloom** category in the command palette.

| Command | What it does |
|---|---|
| Welcome | Open the Octoloom Welcome page: new network, recently built projects, statistics |
| Coverage Map | Every agent network on this machine: policy coverage, authentication, governance, lifecycle and where the assets come from |
| New Agent Network Project | Create a v1 or v2 project skeleton |
| Download Agent Network from Exchange | Pick a published agent network and version, save it in a new workspace folder and open it |
| Open Visual Editor / Open as Text | Switch between canvas and YAML |
| Connect / Disconnect Agent Fabric | Connected-app sign-in |
| Select Agent Fabric Environment | Choose the target environment |
| Connect / Disconnect A²D | A²D API key |
| Connect / Disconnect P4A | P4A personal access token (policy catalog and deployment) |
| Refresh Asset Palette | Reload Exchange / A²D assets |
| Install / Repair Agent Fabric CLI and Prerequisites | Node.js, Java, anypoint-cli-v4, plugin |
| Show CLI Status | Versions and paths |
| Build (validate) Project | `agent-network` build |
| Publish to Exchange / Unpublish from Exchange | Exchange lifecycle |
| Deploy / Undeploy | Runtime lifecycle |
| Set Up Gateways | Gateway setup for the network |
| Run Locally (Docker) / Stop Local Run | v2: run the network on this machine with `run-local` |
| Chat with Deployed Broker | Opens the broker chat for a project |
| Check Deployment Status | Checks every project's brokers again (status lights) |
| Governance: Validate Against Rulesets | Pick rulesets for a project, validate it and see the findings with fixes |
| Governance: Workspace Report | All projects in the workspace with their findings; HTML report |
